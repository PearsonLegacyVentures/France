## Enquiry model
These are private massage **enquiries**, not a booking/payment confirmation. No published local prices or claims of active local therapists. A 6-hour minimum lead time, local timezone `Europe/Paris`, 10:00–19:00 request times. Primary channel: a user-reviewed WhatsApp message to +1 (242) 816-8286. The optional Cloudflare /api/enquiry email channel requires RESEND_API_KEY and BOOKING_FROM_EMAIL; absent secrets it returns a 503 and visitor should use WhatsApp. To avoid dead-end email UX, only WhatsApp submission is shown in the current frontend.
